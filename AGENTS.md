# Working in this repository

This repo is the OVN project website: a **static site generated by Hugo** (theme
`hugo-theme-learn`, vendored under `src/themes/`). There is no backend, no
database and no external service — nothing needs credentials.

## Running it here (Base44 sandbox)

- Everything runs through `docker-compose.base44.yml`, which serves the site with
  `hugo server` from the bind-mounted `src/` directory.
- Entry point: host port 3000 → `http://localhost:3000/`.
- The site is multilingual with `defaultContentLanguageInSubdir = true`, so `/`
  only returns a meta-refresh page: the real English home page is **`/en/`**
  (Spanish: `/es/`). Use `/en/` for health checks and links.
- Base URL is kept root-relative (`--baseURL / --appendPort=false`) so the
  proxied preview origin resolves assets and links correctly. Keep this flag if
  you change the command: Hugo otherwise bakes `localhost:1313` into links.
- `src/layouts/partials/search.html` overrides the theme's partial: it builds the
  search index URL root-relative (`/en/index.json`). The theme concatenated
  `.Site.BaseURL` with the language prefix, which with a path baseURL turned into
  the protocol-relative `//en` and broke search with ERR_NAME_NOT_RESOLVED. Keep
  the override in place when updating the theme.
- Hugo's file watcher works on the bind mount (verified: editing a content file
  triggers "Change detected, rebuilding site"). Content edits need no restart;
  a change to `docker-compose.base44.yml` or the image does.
- Logs: `docker compose -f docker-compose.base44.yml logs -f web`.

## Repo conventions

- `make static` (the CI path) downloads a Hugo binary and builds into `output/`
  with drafts included. That output directory is git-ignored and is **not** what
  the sandbox serves — do not build it to preview changes.
- Do not commit `hugo`, `output/`, or `src/public/`.
- `src/static/support/dist-docs*` holds pre-generated rendered docs and dominates
  content — they are static assets, not Hugo content.
